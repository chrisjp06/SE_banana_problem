# Lab 5: Static Code Analysis — Issues Report

## Identified Issues and Remediation Table

| Issue | Type | Line(s) | Description | Fix Approach |
|---|---|---|---|---|
| **SQL Injection Vector (B608)** | Security (Medium Severity) | 10 | The `registerPet` function uses string formatting (`%s`, `%d`) to insert dynamic variables directly into an SQL query string (`INSERT INTO pets... VALUES ('%s', '%s', %d, 0)`), exposing the database to SQL injection attacks. | Replaced string interpolation with parameterized queries using SQLite placeholder syntax `?` and passing parameters as a tuple: `conn.execute("INSERT INTO pets (...) VALUES (?, ?, ?, 0)", (name, species, age))`. |
| **Insecure Random Number Generator (B311)** | Security (Low Severity) | 22 | `adoptionCode` uses standard library `random.randint(1000, 9999)` which relies on the Mersenne Twister PRNG. This generator is deterministic and unsuitable for generating unique, secure, or unguessable tokens/identifiers. | Replaced `random` with the cryptographically secure `secrets` module: `secrets.randbelow(9000) + 1000`, returning a formatted adoption token `PET-{code}`. |
| **Try-Except-Pass Silent Suppression (B110 / W0718)** | Security & Bug (Low Severity) | 36–37 | `clearUnadopted` catches generic `Exception` and executes `pass`, swallowing critical database errors and unexpected exceptions without logging or remediation. | Replaced broad `Exception` with specific `sqlite3.Error as err:` and added diagnostic error reporting (`print(f"Database error clearing unadopted pets: {err}")`). |
| **Mutable Default Argument (W0102)** | Bug / Reliability | 9 | `registerPet` defines `tags=[]` as a default argument. In Python, default arguments are evaluated once at function definition, causing this list to be shared across all invocations that omit `tags`, leading to state pollution. | Changed default value to `tags=None` and conditionally initialized a fresh list inside the function body (`if tags is None: tags = []`). |
| **Bare Except Clause (W0702 / E722)** | Bug / Code Quality | 29 | `oldestAvailable` uses a bare `except:` clause, which catches all exceptions—including `KeyboardInterrupt`, `SystemExit`, and memory errors—masking unexpected bugs. | Replaced bare `except` by explicitly validating the query result (`if row is not None: return row[0]`) and catching specific `sqlite3.Error as err:`. |
| **Global State Mutation (W0603 / C0103)** | Architecture / Maintainability | 6, 16 | The module defines a global variable `adoption_count = 0` and modifies it inside `adopt` using the `global` statement. Modifying global variables leads to hidden dependencies and concurrency issues. | Replaced the raw global variable with an explicit shelter state structure (`shelter_stats = {"adoption_count": 0}`), eliminating the need for `global` declarations. |
| **PEP 8 Naming Conventions (C0103)** | Style / Convention | 9, 21, 25, 33, 40 | Function names (`registerPet`, `adoptionCode`, `oldestAvailable`, `clearUnadopted`, `shelterStatus`) were written in camelCase instead of PEP 8 compliant snake_case. | Renamed all functions to snake_case (`register_pet`, `adoption_code`, `oldest_available`, `clear_unadopted`, `shelter_status`). |
| **Line Length Exceeded (C0301 / E501)** | Style | 5, 10, 27 | Lines exceeded the maximum allowed length (up to 116 characters), violating PEP 8 (79 characters max) and Pylint standards. | Split multiline SQL statements across triple-quoted strings and formatted function call arguments across multiple indented lines. |
| **Multiple Statements on Single Line (C0321 / E701)** | Style | 41 | In `shelterStatus`, `if adoption_count > 0: return "active"` contained multiple statements on a single line separated by a colon. | Split the condition and return statement across multiple lines with proper 4-space indentation. |
| **Missing Module and Function Docstrings (C0114 / C0116)** | Documentation | 1, 9, 15, 21, 25, 33, 40, 45 | The module and its public functions lacked docstrings explaining their purpose, parameters, and return types. | Added comprehensive PEP 257 docstrings for the module and all functions (`register_pet`, `adopt`, `adoption_code`, `oldest_available`, `clear_unadopted`, `shelter_status`, `main`). |
